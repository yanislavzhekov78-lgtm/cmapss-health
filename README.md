   # cmapss-health

   Remaining-useful-life (RUL) analysis of NASA C-MAPSS turbofan engine data.

   ## Reproduce in 3 commands

```bash
   git clone https://github.com/yanislavzhekov78-lgtm/cmapss-health.git
   cd cmapss-health
   uv sync
```

   Data is not included. Download C-MAPSS from the NASA dataset page and place the files in `data/`.
